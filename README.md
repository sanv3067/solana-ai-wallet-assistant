# Solana AI Wallet Assistant

A beginner-friendly, read-only Solana wallet dashboard built with Python and Streamlit.

## Features
- Reads a public wallet's SOL balance using Solana Mainnet RPC.
- Fetches SOL/USD price from CoinGecko.
- Calculates estimated USD value for SOL only.
- Displays up to the latest 10 transaction signatures, timestamps, slots, and status.
- Shows simple rule-based wallet insights.

## Limitations
- This is currently a read-only dashboard, not an autonomous AI agent.
- It does not connect to Phantom, sign transactions, send payments, or trade.
- SPL token balances and NFTs are not included.
- Transaction history is limited to the latest 10 signatures.
- Insights are rule-based, not generated by an LLM.
- Public APIs may be rate-limited.

## Run on Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
Open the local URL shown in the terminal, usually http://localhost:8501.

## Safety
Enter only a public wallet address. Never paste a seed phrase or private key.
